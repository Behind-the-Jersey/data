# Coverage: what we could map next

Research leads for contributors and agents, **not facts and not ratings**. Each lead has a source URL, but nobody has checked it against the page yet: open the source, and add only what it says, as [CONTRIBUTING.md](../../CONTRIBUTING.md) describes. Compiled on 24 September 2026 and moved here from the website; it's a snapshot. The [issues](https://github.com/Behind-the-Jersey/data/issues) say what's still open, this page doesn't.

- [`targets.json`](targets.json): 46 targets with entities, official team lists, sourced leads and data notes, for agents.
- Every target has an issue (`issue` in `targets.json`). Comment on it before you start, as [CONTRIBUTING.md](../../CONTRIBUTING.md) says. An agent follows [`agents/research.md`](../../agents/research.md).

## Before you start

1. **Not every sport fits the data yet.** Each target has a *shape*:
   - `club-shirt`: clubs or teams with sponsors on the shirt. Fits the data model now. Soccer leagues get the full overview on the website; other sports need the overview generalised (a small change).
   - `org-partner`: sponsors of a league, tour or federation. Fits now as organisation deals (`data/deals/` with `clubId: null`).
   - `event-host`: races, fights and tournaments hosted or title-sponsored by a state. **Needs a new event record** in the schema and a page design.
   - `car-livery`: sponsors on cars. **Needs a "car" placement** and a team page that isn't a shirt.

   Start with `club-shirt` and `org-partner` targets. For the others, put what you find in the pull request description with its sources; it can't go into the data until the model is extended.
2. **Unsourced leads aren't here.** The research also found 147 leads without a source. They were never published, and must be found and sourced again before they're used.
